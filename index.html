02 — Deep dive

StacketPro 3PL: one WMS, eleven outside systems

How we turned a standalone warehouse app into a hub that syncs orders, inventory, billing and CRM data with the platforms its customers already use. stacketwms.com ↗

  1. Problem

    Warehouse data was trapped in silos

    3PL operators received orders from Amazon, Shopify, Walmart and carts like Sellbrite and CartRover, then re-keyed them into billing and accounting tools. Every manual hop added delay and errors, and onboarding a new client meant another one-off workaround.

  2. Approach

    A connector layer, not point-to-point hacks

    • Designed APIs, connectors and webhooks in ASP.NET Core so each platform plugs into a common sync model.
    • Built synchronization jobs to keep orders, stock and payments consistent across systems.
    • Led the dev team through code reviews and priorities; set up Azure DevOps CI/CD for repeatable deployments.
    • Worked directly with US stakeholders to turn integration requests into scoped, shippable features.
  3. Results

    A WMS that fits into the customer's stack

    • 11 live integrations across marketplaces, ERP, accounting, CRM and payments
    • 1 shared sync model, so new connectors follow a known pattern
    • CI/CD automated deployments via Azure DevOps

Personal portfolio of **Syed Yahya Hussaini**, Senior Full Stack Developer and Team Lead with 9+ years building SaaS and cloud applications on ASP.NET Core, Angular and Azure.

**Live site:** [https://yahyahussene.github.io](https://yahyahussene.github.io)

## What's on the site

- **Featured projects:** StacketPro 3PL, Seranova AI, Restro Catering, PricePro and GeoMark
- **Case study:** how StacketPro 3PL was integrated with 11 external platforms
- **About, skills and career milestones**
- **Contact:** email, GitHub, LinkedIn and X

## Tech

Plain HTML, CSS and JavaScript. There is no framework, build step or dependency.

| File | Purpose |
|---|---|
| `index.html` | Page content and structure |
| `styles.css` | Layout, theming (night mode by default, with a light toggle) and responsive rules |
| `script.js` | Theme toggle, live Karachi time, copy-email button, contact form (opens the visitor's email app) and scroll animations |
| `assets/` | Project images (WebP) |

## Run locally

Open `index.html` in a browser, or serve the folder:

```bash
python -m http.server 8000
# then visit http://localhost:8000
```

## Deployment

Pushing to `main` publishes the site through GitHub Pages.
